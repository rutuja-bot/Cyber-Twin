# 3D Reconstruction — Assets

## Overview
Stores textures, materials, and lightweight environment assets used when rendering the 3D cyber infrastructure view and evidence markers.

### Contents
- Lightweight PBR materials and icon textures for devices, servers, and network states.
- Status indicator shaders and glowing textures for compromised node markers.
- Minimal environment lighting and background maps optimized for browser-based Three.js scenes.
