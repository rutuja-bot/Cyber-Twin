# 3D Reconstruction — Blender

## Overview
Houses Blender scripts, scene templates, and asset conversion pipelines for authoring lightweight, low-poly 3D cyber infrastructure models.

### Role in Cyber Twin
- Modeling standard IT and network assets (servers, workstations, network hardware).
- Designing compact 3D evidence pins and event alert markers.
- Optimizing geometry, materials, and draw calls for high-performance Three.js rendering in web browsers.
- Automating GLTF/GLB asset export.
